================================================================================
ПОШАГОВАЯ ИНСТРУКЦИЯ ПО ДЕПЛОЮ И АВТО-ОБНОВЛЕНИЮ НА RENDER.COM
================================================================================

Render.com — это один из лучших и бесплатных облачных хостингов для Node.js приложений.
При этой настройке КАЖДЫЙ ваш `git push` в репозиторий GitHub будет АВТОМАТИЧЕСКИ
собирать и обновлять проект на боевом URL без вашего вмешательства.

--------------------------------------------------------------------------------
ШАГ 1: ПОДГОТОВКА И РЕГИСТРАЦИЯ НА RENDER.COM
--------------------------------------------------------------------------------
1. Перейдите на сайт https://render.com
2. Нажмите «GET STARTED» и авторизуйтесь через ваш аккаунт **GitHub**.
   Это нужно, чтобы Render получил доступ к вашему репозиторию бота.


--------------------------------------------------------------------------------
ШАГ 2: СОЗДАНИЕ ВЕБ-СЕРВИСА (NEW WEB SERVICE)
--------------------------------------------------------------------------------
1. В главной панели Render (Dashboard) нажмите синюю кнопку **«New +»** -> выберите **«Web Service»**.
2. В списке репозиториев найдите ваш репозиторий `trainer-ai-bot` (или название репозитория вашего бота) и нажмите **«Connect»**.
   (Если репозиторий не отображается, нажмите «Configure account» и предоставьте доступ к репозиторию).


--------------------------------------------------------------------------------
ШАГ 3: НАСТРОЙКА ПАРАМЕТРОВ СБОРКИ (BUILD & START COMMANDS)
--------------------------------------------------------------------------------
Заполните поля в форме настройки:

• **Name**: `trainer-ai-bot` (или любое желаемое название приложения).
• **Region**: `Frankfurt (EU Central)` (ближайший регион с минимальной задержкой).
• **Branch**: `main` (или `master` — ваша основная ветка кода).
• **Root Directory**: оставьте пустым.
• **Runtime**: `Node`
• **Build Command**: 
  `npm install && npm run build`
• **Start Command**: 
  `npx tsx server.ts`
• **Instance Type**: `Free` ($0/month)


--------------------------------------------------------------------------------
ШАГ 4: УСТАНОВКА ПЕРЕМЕННЫХ ОКРУЖЕНИЯ (ENVIRONMENT VARIABLES)
--------------------------------------------------------------------------------
Прокрутите форму вниз до раздела **«Environment Variables»** и нажмите **«Add Environment Variable»**:

1. Добавьте переменную:
   • **Key**: `NODE_ENV`
   • **Value**: `production`

2. Добавьте ключ Gemini API (если используется AI):
   • **Key**: `GEMINI_API_KEY`
   • **Value**: `<ваш_ключ_от_Google_AI_Studio>`


--------------------------------------------------------------------------------
ШАГ 5: ЗАПУСК И АВТО-ДЕПЛОЙ (DEPLOYS & AUTO-DEPLOY)
--------------------------------------------------------------------------------
1. Нажмите синюю кнопку **«Create Web Service»** внизу страницы.
2. Render автоматически запустит процесс первой сборки. Вы увидите логи консоли:
   - `npm install`
   - `vite build`
   - `[Trainer AI Bot ver 1.0.0] Listening on http://0.0.0.0:10000`
3. Через 1-2 минуты напротив вашего проекта загорится зеленый статус **«Live»**.
4. Вверху страницы появится ваш бесплатный публичный URL вида:
   `https://trainer-ai-bot.onrender.com`


--------------------------------------------------------------------------------
⚙️ КАК ТЕПЕРЬ РАБОТАЕТ АВТО-ОБНОВЛЕНИЕ?
--------------------------------------------------------------------------------
В Render по умолчанию включена функция **Auto-Deploy**:
- Каждые новые изменения, которые вы делаете и отправляете через `git push`,
  Render мгновенно подхватывает за секунду.
- Он сам пересобирает клиентскую часть (`npm run build`), перезапускает сервер
  и обновляет приложение на вашем сайте.
- Вам больше ничего не нужно прожимать вручную!

--------------------------------------------------------------------------------
ПОЛЕЗНЫЙ ЛАЙФХАК (ФАЙЛ RENDER.YAML):
--------------------------------------------------------------------------------
В коде вашего репозитория уже создан файл `render.yaml`. 
Вы можете нажать **«New +»** -> **«Blueprint»** в Render, выбрать ваш репозиторий,
и Render автоматически заполнит все настройки выше за 1 клик!
