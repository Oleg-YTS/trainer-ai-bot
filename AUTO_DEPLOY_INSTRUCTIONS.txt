================================================================================
ИНСТРУКЦИЯ ПО НАСТРОЙКЕ АВТО-ДЕПЛОЯ (CI/CD AUTO-DEPLOYMENT GUIDE)
================================================================================

1. КАК РАБОТАЕТ АВТО-ДЕПЛОЙ (ПРИНЦИП ДЕЙСТВИЯ)
--------------------------------------------------------------------------------
Авто-деплой позволяет полностью исключить ручную сборку проекта. 
При каждом выполнении команды `git push` в вашу основную ветку (main/master):
1. GitHub автоматически фиксирует новые коммиты.
2. Запускается созданный воркфлоу `.github/workflows/deploy.yml`.
3. Система проводит автоматическое тестирование, устанавливает зависимости (`npm ci`),
   собирает продуктовый бандл (`npm run build`) и загружает его на боевой сервер.


2. ВАРИАНТ 1: АВТО-ДЕПЛОЙ НА СВОЙ VPS / СЕРВЕР (ЧЕРЕЗ GITHUB ACTIONS + SSH)
--------------------------------------------------------------------------------
Это самый надежный и популярный вариант для собственного сервера (Ubuntu/Debian).

Шаг 1. Подготовка сервера (VPS):
1. Убедитесь, что на сервере установлен Node.js 20+ и менеджер процессов PM2:
   npm install -g pm2
2. Склонируйте репозиторий на ваш сервер в папку `/var/www/trainer-bot`:
   git clone <URL_ВАШЕГО_РЕПОЗИТОРИЯ> /var/www/trainer-bot
3. Запустите сервис через PM2:
   cd /var/www/trainer-bot
   npm install
   npm run build
   pm2 start server.ts --name "trainer-bot" --interpreter node_modules/.bin/tsx

Шаг 2. Настройка SSH ключа в GitHub Secrets:
1. Сгенерируйте SSH ключ на сервере: ssh-keygen -t rsa -b 4096
2. Добавьте публичный ключ в `~/.ssh/authorized_keys`.
3. Перейдите в ваш репозиторий на GitHub -> `Settings` -> `Secrets and variables` -> `Actions`.
4. Создайте три секретных переменных:
   • `HOST`: IP-адрес вашего VPS сервера.
   • `USERNAME`: Логин (например, `root` или `ubuntu`).
   • `SSH_KEY`: Содержимое приватного SSH-ключа (`cat ~/.ssh/id_rsa`).

Шаг 3. Замените `.github/workflows/deploy.yml` на следующий код:

```yaml
name: Remote Auto-Deploy to VPS

on:
  push:
    branches: [ main, master ]

jobs:
  deploy:
    runs-on: ubuntu-latest
    steps:
      - name: Deploy to VPS via SSH
        uses: appleboy/ssh-action@v1.0.3
        with:
          host: ${{ secrets.HOST }}
          username: ${{ secrets.USERNAME }}
          key: ${{ secrets.SSH_KEY }}
          script: |
            cd /var/www/trainer-bot
            git pull origin main
            npm ci
            npm run build
            pm2 restart trainer-bot
```

Теперь при каждом `git push` ваш VPS сервер будет автоматически подтягивать код,
пересобирать `dist` и перезапускать бота без простоя (Zero Downtime)!


3. ВАРИАНТ 2: АВТО-ДЕПЛОЙ НА ОБЛАЧНЫЕ ПЛАТФОРМЫ (RENDER / RAILWAY / VERCEL)
--------------------------------------------------------------------------------
Если вы используете облачный хостинг (Render, Railway, Vercel или Koyeb):

1. Зайдите в панель вашего облачного сервиса.
2. Нажмите «New Web Service» и выберите авторизацию через GitHub.
3. Укажите ваш репозиторий.
4. Задайте настройки сборки:
   • **Build Command**: `npm install && npm run build`
   • **Start Command**: `npx tsx server.ts`
5. Включите галочку **«Auto-Deploy»** (по умолчанию включена).
После этого любой `git push` будет автоматически собирать и обновлять проект!


4. ВАРИАНТ 3: АВТО-ДЕПЛОЙ ЧЕРЕЗ WEBHOOK (ДЛЯ REG.RU / TIMEWEB / CPANEL)
--------------------------------------------------------------------------------
1. На вашем хостинге создается скрипт `deploy.php` или `deploy.sh`.
2. В GitHub перейдите в `Settings` -> `Webhooks` -> `Add webhook`.
3. Укажите URL файла `https://your-domain.com/deploy.php` и выберите событие `Just the push event`.
4. GitHub будет посылать сигналы вашему хостингу при каждом пуше.


5. ПРОВЕРКА И ЛОГИ СБОРКИ
--------------------------------------------------------------------------------
Все статусы автоматических деплоев и историю вы можете смотреть во вкладке 
**«Actions»** внутри вашего GitHub репозитория. Если в коде будет ошибка — GitHub 
пришлет уведомление и НЕ заменит рабочую версию на сервере.
